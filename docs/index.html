Every track,in key.

KeyTool finds the tempo and key of every song in your library, writes them into the files and shows you which tracks mix together.

Download for Windows Source on GitHub

Free. Windows, 64-bit. No FFmpeg or Python install needed.

5 formats
MP3, WAV, FLAC, OGG and M4A, single files or whole folder trees.
24 keys
In Camelot, sharps, flats or Open Key, with a confidence for each result.
20× faster
When a file already has its key tag, only the tempo gets analysed.
5 languages
English, German, Spanish, French and Italian. Dark or light.

Analysis you can check

Drop in a folder and KeyTool works through it in the background. Every result comes with a confidence, and anything you correct by hand stays corrected.

  • Tempo from beat tracking with octave correction, so a 64 BPM guess becomes 128.
  • Key with drums filtered out first, then three key profiles voting together.
  • Tags written for you: BPM and key land in the file, readable by rekordbox, Serato and Traktor. You can switch this off.
  • Only what is missing: existing tags are kept, and the rest gets analysed.

A deck that knows the song

Double-click a track to load it. The deck shows the parts of the song, your Serato cue points and how it sounds a semitone up or down.

  • Serato cues read from the file, moved by dragging, saved back so Serato DJ sees them.
  • Song sections detected for you: intro, verse, chorus, build-up, drop, outro. Rename or move them in the waveform.
  • Transpose ±1 semitone at the original tempo, with the new key shown on the button.
  • Zoom from the whole track down to a few seconds, with the mouse wheel.

See what fits before you play it

Load a track and every other track tells you whether it mixes: same key, a harmonic neighbour or a clash, plus the tempo difference in percent.

  • Camelot wheel filter: click a key, right-click to add its neighbours, Shift for ±1 semitone.
  • Search everything: title, artist, album, year, BPM range, keys and your own keywords.
  • Harmonic match finds tracks within ±6 % tempo that fit your selection.
Same key as the deck, or the same after transposing.
Harmonic neighbour: one step around the wheel, or the relative major or minor.
Clashes. Try transposing the deck by a semitone.
±%
Tempo difference to the deck, dimmed beyond 6 %.

Up and running in a minute

  1. Download

    Get the zip for Windows from the latest release.

  2. Unzip and start

    Put the folder anywhere and open KeyTool.exe. Nothing else to install.

  3. Add a folder

    Choose your music folder. Analysis starts right away and the tags are written as each track finishes.

Prefer the source? Install Python 3.10–3.13 and double-click start.bat. It sets everything up on the first start and installs new packages after updates. build_exe.bat builds your own executables.

Questions

What does KeyTool change in my files?

Only tags: BPM, key and audio type after analysis, the metadata you edit, and the cue points you move. The audio itself is never touched. Writing tags can be switched off in the settings.

Will rekordbox, Serato and Traktor read the keys?

Yes. The key tag uses sharps by default (for example F#m), which all three understand. You can choose Camelot, flats or Open Key instead.

Is there a Mac version?

Not yet. KeyTool runs on Windows for now; you can run it from the source code on other systems with Python.

Do I need Claude to use it?

No. KeyTool is a complete desktop app. The MCP server is an extra for people who want to work with their library through an AI assistant.

Where is my library stored?

In a single database file in %APPDATA%\KeyTool, shared by the app and the MCP server. Nothing is uploaded anywhere.
